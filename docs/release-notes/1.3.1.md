# com_biotime 1.3.1

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Find Tables: "Some columns".** `auth_user` (ZKBioTime's user accounts) was shown as *NOT READABLE*
although the portal reads it. That is by design: only eight of its columns are granted to the
portal, never the password. Find Tables now shows such a table as **Some columns**, counts the
columns it may read, and marks the others *not granted* (they are never read).
