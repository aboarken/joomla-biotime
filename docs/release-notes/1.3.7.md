# com_biotime 1.3.7

Update from **System → Update → Extensions**, or install the attached package. No database changes.

This release follows a full audit of the extension (security, data, Joomla conventions, build).
No critical or high-risk problem was found; the details are in `docs/AUDIT.md`.

**Security**
- User Mappings → **Confirm** only confirms users waiting for approval (or suspended), for the
  employee their match found. It can no longer map someone to an employee code they typed into
  their own profile.
- **Export PDF** works only from the Manager Dashboard's own buttons; a link from another page is
  refused, so nobody can use up a manager's hourly reports.
- My Approvals never shows an older copy of the requests waiting for you.
- Settings changes are recorded in the audit log (which settings, never their values).

**Fixes**
- Days on leave show the leave's name instead of **Absent**, whatever the leave type is called in
  ZKBioTime (also in Arabic).
- My Leaves, My Approvals and the Manager Dashboard show a clear message when ZKBioTime cannot be
  reached (they showed `COM_BIOTIME_ERROR_…`).
- Updating no longer resets the date format to DD/MM/YYYY.
- The Manager Dashboard opens faster for large teams.
