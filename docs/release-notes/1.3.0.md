# com_biotime 1.3.0

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**New: Find Tables** (Components → ZKBioTime → Find Tables, super users only). Like *Find Endpoints*
in the ServiceDesk Plus portal, it shows what ZKBioTime's database holds, to check the portal's
tables on your server or to identify the tables a new feature needs (for example the Leave Request).

- **Diagnostics**: one click writes a report to copy into a support request: settings (no address,
  user or password), whether the connection is encrypted and read-only, each table the portal
  reads (found, readable, about how many rows), the codes your server stores for statuses and punch
  types, and how much ZKBioTime calculated recently.
- **Tables**: every table the portal knows, what it holds and which page reads it, plus every other
  table the database user can see.
- **Check a table**: its columns, keys, which tables it points to and which point to it, how many
  rows it has, how often each column is filled, and the values of its status and type columns.

Everything is read with the portal's read-only database user; nothing is changed. No personal data
is shown: names of tables and columns, types and counts only.
