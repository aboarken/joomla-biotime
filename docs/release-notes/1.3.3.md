# com_biotime 1.3.3

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Copy report and Download report work after updating.** Joomla's extension update does not tell
browsers that a script or style has changed, so after the last update browsers kept running the
old Find Tables script and both buttons did nothing. Every script and style of the component now
carries its version in its address, so browsers always load the files of the installed release.

**Download report** is now sent by the server: it works whatever the browser allows.
