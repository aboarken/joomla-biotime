# com_biotime 1.3.2

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Find Tables → Diagnostics:** *Copy report* now copies the report (it did nothing on some sites)
and says *Copied to the clipboard.* If a browser does not allow copying, the report is selected
for Ctrl+C. The new **Download report** button saves the report as a text file.
